## 关键结果

主实验为22个确定性组合、72批次2880项任务，每组960项；另有48项时间因素分离场景、3项截止边界测试和独立存储实验。

| 方案 | 主实验额外业务效果 | 主实验未生效任务 |
|---|---:|---:|
| A：编号与重试 | 724 | 0 |
| B：事务去重与固定TTL | 106 | 0 |
| C：增加截止时间、过期拒绝及核查 | 0 | 88 |

**C在本次覆盖场景中没有重复生效，但会拒绝过晚任务，不能无条件保证“不漏不重”。** 长TTL的B在本次相应延迟范围内也没有重复。研究保证止于模拟接收端数据库，未验证真实短信送达；逻辑时间不是网络性能测试。

## 复现

下载并解压`experiment-full.zip`，进入`alert-lab`目录。需要Node.js 24，使用内置SQLite，无第三方运行依赖。

```powershell
node --test test.mjs
node audit-all.mjs
```

重新运行实验的命令见包内README及报告第8节。主实验正式数据在`runs/verified`，补充实验在`runs/supplement`，存储实验在`runs/storage`。`runs/main`仅保留初轮记账问题，不作为正式结论。

## AI协作与原创探索

对话从原始消息导出，包含失败、修正与方案演进，导出截止点和附件范围见对话文件开头。当前快照之后新增的对话需继续补充。

幂等、事务、outbox和有效期是已有方法。本项目的课程探索是构造跨去重保留期限的告警故障反例，设计期限与清理联动的机制，并量化其可用性和存储代价，不声称发明新的通用分布式算法。
